breakthrough package repository

APT and RPM repository metadata for breakthrough, a TUI file manager for Linux sysadmins. Packages are built and signed automatically from tagged GitHub releases.

Debian / Ubuntu (apt)

curl -fsSL https://pkg.breakthrough.jens-schendel.com/signing-key.asc | sudo gpg --dearmor -o /usr/share/keyrings/breakthrough.gpg
echo "deb [signed-by=/usr/share/keyrings/breakthrough.gpg] https://pkg.breakthrough.jens-schendel.com/apt stable main" | sudo tee /etc/apt/sources.list.d/breakthrough.list
sudo apt update
sudo apt install breakthrough

Fedora / RHEL / openSUSE (dnf/zypper)

sudo rpm --import https://pkg.breakthrough.jens-schendel.com/signing-key.asc
sudo tee /etc/yum.repos.d/breakthrough.repo <<'EOF'
[breakthrough]
name=breakthrough
baseurl=https://pkg.breakthrough.jens-schendel.com/rpm/stable/$basearch
enabled=1
gpgcheck=1
gpgkey=https://pkg.breakthrough.jens-schendel.com/signing-key.asc
EOF
sudo dnf install breakthrough

Signing key: signing-key.asc
